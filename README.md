# 多格式排版 v0.2.8 · 四角自由缩放版

把 Word / Excel / PDF / 图片混排成一份 A4 打印稿的本地工具。文件在本机完成转换与排版，不联网、不依赖外部 CDN，也不改动原文件。

## 目录结构

```
index.html                  主程序（pdf-lib、pako 等库已内联）
使用说明.txt                 完整操作说明
assets/pdfjs/               PDF.js 运行时（含 cmaps 与标准字体）
第三方许可说明/               所有第三方库的许可证与版权声明
验收证据/                    v0.2.8 的验证记录、导出样例与校验结果
```

## 运行

程序需要**通过本地 HTTP 服务打开**，不能直接双击 `index.html`（Office 转换依赖本地服务）。任选一种：

```bash
# 方式一：Python
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式二：Node
npx serve .
```

原交付包中另附 `启动多格式排版.exe`，会自动起本地服务并打开浏览器。该可执行文件不在本仓库内，见下方「发布包」。

## 功能要点

- **混排**：Word DOC/DOCX、RTF、Excel XLS/XLSX、PDF、PNG、JPG，一次多选或分次添加，合并为一份 PDF 打印稿
- **版式**：每张 A4 排 2 / 4 / 8 页，纵向 210×297mm 或横向 297×210mm
- **四角自由缩放**：点击内容后拖动任意一角，对角固定；横拖只改宽、竖拖只改高、斜拖同时改宽高；按住 Shift 保持比例。宽高各支持 25%–200%
- **拖动换序**：按住内容拖到另一个格子，出现「松手交换」后松开即可跨页、跨纸交换
- **撤销 / 恢复**：撤销上一次调整，或恢复 100% 居中、全部恢复
- **键盘**：方向键移动 1pt（Shift 为 10pt）；角点上左右键调宽、上下键调高；`+` / `-` 等比缩放；`Alt` + 方向键与相邻页交换
- **导出**：下载 A4 打印稿，或下载处理清单（来源文件、来源页、输出位置、宽高比例、位移、纸张方向）

## 环境依赖

- Windows 桌面环境
- Word / RTF 转换需要已安装可用的桌面版 Word；Excel 需要桌面版 Excel（保留 WPS 自动化接口作为备选，但本版本**未完成 WPS 实机验收**）
- Excel 按工作簿现有打印区域、分页和可见工作表导入，隐藏页不排入。若表格内容缺失，先检查打印区域与打印预览
- 已在 Microsoft Word/Excel 16.0 + Chrome 上完成验证；未声称覆盖所有浏览器或 WPS 版本

## 限制

- 每次最多 100 个文件、累计 100 页、单个文件 25MB
- 调整的是整页内容的位置与比例，**不能在网页里修改 Word 文字或 Excel 单元格**
- 不识别发票金额、不做发票验真
- 暂不支持 OFD、旋转 PDF 页、加密文件、带宏文档、外部数据连接
- 刷新或关闭页面后，本次导入与调整不会保留，请先下载结果
