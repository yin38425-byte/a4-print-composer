# 文档拼版

Windows 本地文档拼版工具。把 Word、Excel、PowerPoint、PDF 和图片合并到一份 A4 打印稿，直接在预览中移动、缩放和交换页面。

当前版本：**v0.2.27 · 追加文件保留排版版**。

[下载 v0.2.27 Windows 完整程序](https://github.com/yin38425-byte/a4-print-composer/releases/download/v0.2.27/wenjian-pinban-v0.2.27-win.zip)

页数上限已从 100 页提高到单份文档及每批累计 300 页。单个文件的容量上限仍是 100 MB（按 1024 × 1024 字节计），与页数限制不同。上传框下方会保留导入错误，直到关闭或重新导入成功；转换办公文件时显示当前文件和处理状态。添加失败时保留原有文件和打印稿。

## 功能

- 支持 DOC、DOCX、RTF、XLS、XLSX、PPT、PPTX、PDF、PNG、JPG。
- 可以一次多选，也可以分次添加，按文件和原始页序合并。
- A4 横向或纵向，每张纸排 2、4、6、8 页来源内容。
- 生成后切换页数或纸张方向会保留当前预览，点击“更新打印稿”后替换输出；新预览默认完整显示首张 A4。
- 横向与纵向的空预览都按可用高度显示完整纸张；切换方向时同步重算尺寸。
- 点击打印稿中的一张原稿页，点删除图标或按 Delete、Enter 即可从打印稿移除；后续页自动补位并更新 PDF。原文件不变，撤销、重做和全部恢复都可找回移除的页。
- 在 A4 内拖动调整位置；拖到另一个格子交换页面，按住 Alt 可越格移动。右键可调整重叠层次。
- 拖角自由改变宽高，对角固定；横拖只改宽，竖拖只改高，Shift 保持当前比例。
- 顶部工具栏可撤销、重做和全部恢复；10%–200% 连续缩放时自动多页并排，也可展开预览。全屏默认 60% 并保留留白，单页围绕画面中心缩放；退出全屏后恢复原预览比例，再次进入保留上次全屏比例。
- 生成后继续添加文件，旧预览和已有页面调整保留；点击“更新打印稿”把新页接在末尾，继续编辑。
- 桌面端左侧文件与排版设置固定，右侧打印纸独立滚动；下载入口和工具栏保持可见。窄窗口改为上下排列。
- 生成打印稿后，预览操作合在一行；下载按钮显示为“下载”，撤销、重做、全部恢复与缩放仍在同一栏。
- 选中内容后拖顶部圆形手柄旋转，接近 0°、90°、180°、270° 自动吸附到准确直角。
- 添加文件时比对实际内容；相同文件可选择跳过或仍然加入，选择加入后导出保留重复内容。
- 下载 PDF 与处理清单。Word 转换结果末尾完全空白的页会跳过，数量记录在处理清单中。
- 文件在本机处理；运行所需网页资源随完整程序提供。

## 分段排版

在左侧“排版设置”中展开“分段排版”，第一条规则直接出现；每条规则在一行中指定“从第几张 A4 起、每张放几页、纸张横向或纵向”。页数与方向点击切换；新规则初始采用上方全局方向，之后独立设置。编号指输出的 A4 纸张，不是原稿页码。设置完成后统一点击“生成打印稿”，生成前后都可以设置分段。

更改分段时保留当前内容顺序，受影响部分重新适配大小、位置和角度，前面的纸张保持不变；“撤销”可以恢复分段及原来的调整。重复、无效或超出实际输出的分段起点会显示说明，不会替换已有结果。删页后暂时超出输出张数的已有分段规则会保留，并在页数恢复后重新生效。

六页布局：A4 横向 3 列 × 2 行，纵向 2 列 × 3 行。纸内不绘制工具添加的边框和来源标签；原文件自身的图形和边框仍保留。编辑时的角点不会导出。

## 运行条件与格式说明

需要 Windows。PDF、图片直接处理；Word、Excel、PPT 需要电脑安装可用的相应桌面 Office 程序。

PPT/PPTX 的每张幻灯片作为一页导入，包含隐藏页，不导入备注页。动画与视频不播放，视频区域保留办公软件可导出的静态封面。已用带指定封面的内嵌视频进行测试；不保证所有编码和特殊对象都能正常转换。外链媒体需要先在 PowerPoint 中嵌入或改成静态图片。

Excel 按原工作簿的打印区域、分页和可见工作表导入。复杂版式、字体替代请检查导出结果。

保留了 WPS 自动化接口备选，但尚未完成 WPS 实机兼容验收。当前不是微信小程序，手机无法运行 Windows 助手；也不能仅通过 GitHub Pages 使用 Office 转换。

每批最多 100 个文件、累计 300 页；单份文档最多 300 页，单个文件大小不超过 100 MB。暂不支持加密、带宏文件、外部数据连接、OFD 和旋转 PDF 页。调整的是整页大小与位置，不能编辑 Word 文字、Excel 单元格或 PPT 中的单个元素；不提供文字识别。

## 使用完整程序

如果使用已构建的发布 ZIP，先完整解压，再双击 `启动文档拼版.exe`，保留助手窗口。默认浏览器会打开本机页面，也可复制助手提供的地址到 Edge 或 Chrome。直接双击 `index.html` 会被浏览器的 `file://` 限制拦住 PDF 预览；页面现在会在导入前提示正确打开方式。

不能只复制 EXE 或 HTML：`OfficeConvert.exe`、`assets/`、许可说明等文件均需保留。运行不需要 Node.js，也不依赖外部 CDN 或 VPN。

## 从源码构建

开发环境：Windows、Node.js 24+（含 npm）、.NET Framework 4.x 编译器。转换办公文件还需安装桌面 Office。

在仓库根目录运行：

```powershell
npm install
npm run build
npm test
```

构建输出为 `dist/`。该目录应完整打包给使用者。首次安装开发依赖需要网络；完整程序的本地排版不需要联网。

## 源码目录

| 路径 | 内容 |
| --- | --- |
| `src/LocalLayout.cs` | 本机 HTTP 助手及转换任务调度 |
| `src/OfficeConvert.cs` | Word、Excel、PowerPoint 转 PDF |
| `src/layout-core.js` | 页面合并、几何位置和 PDF 导出 |
| `src/direct-*.js`、CSS、HTML | 拖动、缩放、换序及预览 |
| `workbench-shell.html` | 页面基础模板 |
| `scripts/`、`src/build.cjs` | 构建与基础测试入口 |
| `src/qa/`、`qa/` | 人工生成的测试输入，不含真实用户资料 |
| `licenses/` | 第三方组件许可说明 |

## 验证

基础测试覆盖分段分页、混合纸张方向、六页横纵向、旋转吸附与 PDF 输出、自由/等比缩放、对角固定、拖动换序、撤销/重做、重复文件选择和空白页处理。浏览器验收使用独立 Chrome 和模拟文档，检查真实文件导入、转换请求、预览及 PDF 下载。

启动构建后的助手后，可使用其显示的本机地址执行 PPT 混排测试（需要 Chrome 与桌面 Word、Excel、PowerPoint）：

```powershell
node src/test-ppt-browser.cjs "助手显示的本机地址" src/qa/ppt artifacts/ppt
```

分段浏览器验收：

```powershell
node src/test-segments-browser.cjs "助手显示的本机地址" artifacts/segments
```

`src/make-ppt-fixtures.py` 与 `src/PptFixture.cs` 用于生成模拟视频和演示稿；Python 样例生成需要 Pillow 和 python-pptx，PPT 原生样例生成需要 PowerPoint。它们不是程序运行依赖。
